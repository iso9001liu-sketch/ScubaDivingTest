# 蓝洞边缘 · ScubaDivingTest

一款单文件、无需安装的 2D 水肺潜水模拟游戏。打开 [开始游戏](https://iso9001liu-sketch.github.io/ScubaDivingTest/dist/) 即可游玩。

## 操作
- `↑ / W`：上升；`↓ / S`：下潜
- `← / A`、`→ / D`：水平移动
- 触屏设备可使用方向按钮
- 选择 OW（18m）或 AOW（30m）训练深度
- 点击配平按钮切换中性浮力，点击观察生物记录海洋生物

## 模拟内容
- 深度增加时环境压力上升，耗气随绝对压力倍增
- 简化氮负荷提示
- 岛礁浅台、珊瑚断崖、深水沙地与鱼群
- 实时深度、气瓶、潜水时间、浮力和潜水日志

本游戏为教学演示，物理模型经过简化，不可用于真实潜水规划。真实潜水请遵守培训、潜伴及潜水电脑指引。
